# Sifu Nathan's Wushu Academy — build plan (condensed)

Profile: solo · pause-at-will management with real-time mini-games · abstract space ·
vs system (rival academy) · authored progression + procedural recruits · win outcome
(National Final, week 24) with endless continue · session 20–40 min ·
engagement: accumulation + execution.

Experience formula: the player feels like a proud sifu because the game constantly
turns their training choices and timing skill into visible student growth, sash
ceremonies and tournament glory.

Core loop: recruit → assign weekly training (or run guided-form / sparring
mini-games) → end week (gains, tuition, fatigue) → sash exams (rhythm mini-game) →
tournaments every 4 weeks (stat-vs-scaled-rival sim, light rng) → reinvest gold in
hall / equipment / instructors.

Verbs: recruit, assign, perform (rhythm), spar (timing), compete, upgrade.
Uncertainty: execution skill, recruit rolls, tournament variance, rival scaling.
Anti-snowball: upgrade costs scale, rivals scale with tier, prestige never lost.

Story: Master Shen of Iron Serpent Academy recurs at weeks 8/16/24; Nathan backstory
between milestones. Win state at week-24 National Final; endless play afterwards.

Delivery: desktop + mobile + gamepad, canvas 2D at 960x540 virtual res, fixed
60 Hz timestep, seeded RNG, strings external in strings.js, dev overlay via ?dev=1.
